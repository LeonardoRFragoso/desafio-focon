# Ativos de Marca - Fócon Engenharia

Ativos de marca fornecidos pelo candidato.

## Arquivos

- **focon-colorida.jpeg** - Imagem quadrada colorida (6.3 KB)
- **focon-logo-horizontal.png** - Logo horizontal colorida (10.8 KB)
- **focon-logo-white.png** - Logo branca para fundos escuros (26.5 KB)

## Diretrizes de Uso

### Logo Horizontal (focon-logo-horizontal.png)
- Usar em superfícies claras
- Preservar proporção
- Usar `object-fit: contain`

### Logo Branca (focon-logo-white.png)
- Usar em fundos verde-petróleo ou escuros
- Preservar proporção
- Usar `object-fit: contain`

### Imagem Quadrada (focon-colorida.jpeg)
- Usar em áreas compactas (ex: login)
- Não ampliar excessivamente
- Usar `object-fit: contain`

## Implementação

Todos os ativos utilizam:
- `alt="Fócon Engenharia"` para acessibilidade
- `object-fit: contain` para preservar proporção
- Caminhos relativos sem inline/base64

## Escopo

Estes ativos são aplicados apenas na Macrofase 1 em:
- Login
- Layout autenticado básico
- Favicon (se compatível)
- Metadados

O refinamento visual completo está reservado para Macrofases 2 e 3.
